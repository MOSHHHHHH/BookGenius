# BookGenius 3.0 📚

**BookGenius** הוא כלי אינטרנטי מתקדם המעניק חוויית כתיבת ספרים מונחית בינה מלאכותית (AI). המערכת מלווה את המשתמש בתהליך יצירה מובנה – החל מגיבוש הרעיון ועד להפקת ספר מושלם ומעוצב, תוך שימוש בממשק משתמש מודרני ונוח.

## 🔗 גישה ישירה
ניתן לגשת לכלי בכתובת: [https://moshhhhhh.github.io/BookGenius](https://moshhhhhh.github.io/BookGenius)

## ✨ תכונות עיקריות

* **תהליך עבודה מדורג (Step-by-Step):** מערכת שלבים אינטואיטיבית הכוללת הגדרת פרטי הספר, בניית תוכן עניינים מפורט וכתיבת הפרקים עצמם.
* **ממשק Picture-in-Picture (PiP) ייחודי:** תמיכה בעבודה עם חלון צף מובנה המאפשר להעתיק הנחיות (Prompts) ולהמשיך בכתיבה מול מודלי שפה חיצוניים (כמו ChatGPT, Claude וכו') מבלי לעבור בין טאבים.
* **תמיכה בתוכן עשיר:**
    * **קוד:** הצגת קטעי קוד עם הדגשת סינטקס (Prism.js).
    * **מתמטיקה:** תמיכה בנוסחאות מורכבות (MathJax).
    * **דיאגרמות:** יצירת תרשימי זרימה ודיאגרמות (Mermaid.js).
    * **מוזיקה:** הצגת תווים (ABCJS).
* **עיצוב ותצוגה מקדימה:**
    * בחירה בין מספר ערכות נושא: קלאסי, אקדמי, מינימליסטי ומודרני.
    * תצוגה מקדימה מלאה בזמן אמת הכוללת תוכן עניינים אינטראקטיבי וניווט מהיר.
* **ניהול ושמירה:** המערכת שומרת את ההתקדמות באופן מקומי (Local Storage), כך שניתן לחזור ולהמשיך את כתיבת הספר בדיוק מהנקודה שבה הפסקתם.

## 🛠 טכנולוגיות

* **Frontend:** HTML5, CSS3 (Modern UI/UX עם תמיכה מלאה ב-RTL), JavaScript (ES6+).
* **Libraries:** * **Font Awesome:** לאייקונים.
    * **Google Fonts:** שימוש בגופנים Heebo, Frank Ruhl Libre ועוד.
    * **Prism.js:** להדגשת קוד.
    * **Mermaid.js:** לתרשימים.
    * **MathJax:** להצגת LaTeX.

## 🚀 הוראות שימוש

1.  **שלב 1 (הגדרות):** הזינו את שם הספר, הז'אנר ותיאור כללי כדי שה-AI יבין את ההקשר.
2.  **שלב 2 (בניית שלד):** צרו את רשימת הפרקים ותתי-הפרקים.
3.  **שלב 3 (כתיבה):** השתמשו ב-Prompts המובנים כדי לכתוב כל פרק בנפרד (ניתן להיעזר בחלונית ה-PiP).
4.  **סיום:** לאחר השלמת כל הפרקים, עברו לתצוגה המקדימה, בחרו את סגנון העיצוב המועדף עליכם והדפיסו ל-PDF או שמרו את התוצאה.
